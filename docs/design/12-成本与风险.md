## 13. 成本模型

| 成本项 | 量级 | 影响因素 |
| --- | --- | --- |
| 拆解（每项目一次） | 150k–400k tokens | 仓库规模、需求清晰度 |
| 接口 + 测试（每模块） | 40k–120k tokens | 模块复杂度；**3.0 新增成本** |
| 实现（每任务） | 20k–80k tokens | 上下文、重试次数 |
| 平台复跑 | 1–10 分钟 CPU/次 | 信任分 |
| 集成全量 | 5–60 分钟 CPU/次 | 项目规模、测试套件 |
| 人工评审 | 5–15 分钟/任务 | 图审批 + 抽样 |

**接口 + 测试约占单模块总 token 的 25–35%。** 这是有意的交换：

> 用 30% 的前置成本，换掉集成阶段全盘返工的风险。分布式开发里，返工成本是前置成本的 5–10 倍。

连这三成都不愿意付，那就别并行。

## 14. 风险登记册

| # | 风险 | 触发信号 | 对策 | 残余 |
| --- | --- | --- | --- | --- |
| R1 | 切分粒度不当 | 单任务 diff 中位数 < 50 或 > 600 行 | V5 + 人工审批 | 中 |
| R2 | 并行度低（热文件） | 图的理论并行度 < 2 | 三策略（§10.4），否则换项目 | 高（结构限制） |
| R3 | 验收造假 | 复跑失败率 > 5% | 冻结 + 红测试 + 信任分 | 低 |
| R4 | 集成反复失败 | 同 group repair ≥ 2 次 | 升级 needs_human，重拆子图 | 中 |
| R5 | 评审疲劳 | 人工评审 > 20 分钟/任务 | 只审 diff + 抽检 | 中 |
| R6 | 环境差异假失败 | 复跑失败但本地绿 | 固定镜像 digest | 中 |
| R7 | 供应商风控 | 终端账号异常 | 终端侧限速；平台不参与 | 中（不可控） |
| R8 | 平台成瓶颈 | 单库 QPS > 50 | 只读副本 + 缓存 | 低 |
| R9 | 许可证污染 | 出现 GPL 片段而项目是 MIT | SCA 纳入 L2 | 中 |
| R10 | 成本失控 | 单任务 token > 200k | 看板告警 + 粒度回退 | 中 |
