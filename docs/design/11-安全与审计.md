## 12.1 三种凭证

| 凭证 | 持有者 | 用途 | 是否违反"不持模型凭证" |
| --- | --- | --- | --- |
| 模型 API Key | 终端 | 调模型 | 不涉及，平台永不见 |
| 终端 token | 平台签发 | 调 OpenVow | 不违反（不是模型凭证） |
| 提交签名（可选） | 终端私钥 | 证明来源 | 不违反 |

**平台必须持有终端 token**，否则任务池可被任意投毒。

## 12.2 集成容器威胁模型

在容器里跑终端提交的 `build.rs` / `npm install` / `Makefile`，等于让陌生代码在你机器上执行。规格缺一不可：

| 项 | 规格 |
| --- | --- |
| 网络 | `--network=none`；需装依赖时走只读包代理（白名单域名） |
| 文件系统 | rootfs 只读；工作区可写；`tmpfs` 做 home 与临时目录 |
| 用户 | 非 root（uid 1000）；`--cap-drop=ALL` |
| 隔离 | seccomp 默认配置；禁止挂载 docker.sock；禁止 privileged |
| 资源 | 2 CPU / 4GB / 60 分钟 / 磁盘 5GB |
| 宿主 | 理想为独立 runner 节点，与数据库网络隔离 |
| 镜像 | 固定 digest，写入日志便于复现 |

`npm install` 的 postinstall 脚本本身就是任意代码执行，包代理只能放行下载，不代理任意域名。

## 12.3 审计

每个产物必须回答五个问题：谁、何时、基于什么、用什么模型、通过了什么。

| 字段 | 来源 | 可信度 |
| --- | --- | --- |
| `terminal_id` | 平台（token 推导） | 高 |
| `task_id / attempt` | 平台 | 高 |
| `base_commit` | 平台 | 高 |
| `harness / model_family / prompt_hash` | 终端自报 | 低，标 `unverified` |
| `acceptance_result` | 平台复跑或终端声明 | 分档：`replayed` / `self_reported` |
