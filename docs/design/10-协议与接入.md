## 11.1 端点总表

| 方法 | 路径 | scope | 说明 |
| --- | --- | --- | --- |
| POST | `/v1/claim` | worker/planner | 原子认领（含写集互斥） |
| POST | `/v1/heartbeat` | worker/planner | 续租 |
| POST | `/v1/checkpoint` | worker/planner | 中间产物 |
| POST | `/v1/submit` | worker/planner | 提交结果与证据 |
| PUT | `/v1/artifacts/{sha256}` | worker/planner | 上传二进制 |
| GET | `/v1/artifacts/{sha256}` | worker/planner | 下载（含上游产物） |
| GET | `/v1/tasks/peek` | any | 只看不拿 |
| POST | `/v1/graphs` | planner | 提交图草案 |
| GET | `/v1/graphs/{id}` | any | 读图 |
| POST | `/v1/graphs/{id}/validate` | planner | 重跑 V1–V8 |
| POST | `/v1/graphs/{id}/approve` | **human** | 批准（生成新 version） |
| POST | `/v1/graphs/{id}/reject` | **human** | 驳回 + reason |
| POST | `/v1/terminals` | admin | 发 token |
| DELETE | `/v1/terminals/{id}` | admin | 吊销 |
| GET | `/healthz` | none | 存活探针 |

**权限写死在表里**：planner 拿不到 approve；执行终端拿不到 approve；集成资格由 `kind` 决定，不由 token 决定。

```json
  "task_id": "N-03-7f21",
  "lease_id": "L-9c2e",
  "attempt": 1,
  "base_commit": "9c1f3ab",
  "files": [{ "path": "src/parser/impl/mod.rs", "sha256": "…" }],
  "evidence": {
    "exit_code": 0, "tests_total": 24, "tests_passed": 24,

```

`evidence` 是声明，不是结论；结论来自 L3 的复跑与退出码。

## 11.3 错误码

| 码 | HTTP | 含义 | 终端应做 |
| --- | --- | --- | --- |
| `lease_expired` | 409 | 租约被回收 | 停手，丢弃本地改动 |
| `write_conflict` | 409 | 写集冲突 | 换任务 |
| `deps_unmet` | 409 | 前驱未 accepted | 换任务 |
| `frozen_file_modified` | 422 | 动了冻结文件 | 还原后重提 |
| `path_outside_writes` | 422 | 提交了写集外文件 | 删除后重提 |
| `acceptance_failed` | 422 | L3 未通过 | 修正后重试 |
| `schema_invalid` | 422 | L0–L2 失败（带 violations） | 修正后重提 |
| `rate_limited` | 429 | 并发/频率超限 | 退避 |

## 11.4 接入方式：MCP 适配器优先

Claude Code、DSH 都是批处理式 CLI：给一段提示，跑完退出，**不会每 5 分钟调 heartbeat**。所以接入不是"写一段 System Prompt"，而是：

| 形态 | 适用 | 说明 |
| --- | --- | --- |
| **MCP server（首选）** | Claude Code 等支持 MCP 的 Harness | 暴露 5 个工具，agent 在循环里自行调用 |
| CLI wrapper | 只接受命令行的 Harness | `openvow run -- <harness>`，wrapper 负责续租、收产物、提交 |
| 原生 SDK | 自研 Agent | 直接调 HTTP |

```
openvow_claim(kinds) -> {task, lease, repo, frozen[], resume}
openvow_heartbeat(lease_id) -> {remaining_seconds}
openvow_checkpoint(lease_id, files[], note) -> {checkpoint_id}
openvow_submit(lease_id, files[], evidence) -> {accepted, violations[]}
```

> 协议容易抄，适配器不容易。适配器才是产品的一部分。
