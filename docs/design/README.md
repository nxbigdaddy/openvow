## 5. 维护规则

1. **章节号是锚点，不随文件移动。**
   一册可以拆、可以合，但 `§9.2` 永远指校验体系的第二小节。新增内容应插在所属章节内部（§9.2.1），不要重排全局编号。

2. **单一真源。**
   同一事实只写在一册里，其他地方用链接引用。发现两处都在描述同一件事，就是该合并的信号。

3. **合订本由工具生成。**
   ```bash
   python tools/build-pdf.py
   ```
   它会按文件名顺序拼接本目录下所有 `*.md`（README 在最前），生成 `docs/OpenVow-设计文档-合订本.pdf`。**不要手改 PDF。**

4. **改完文档，检查三件事**：交叉引用的编号是否还有效、被替换的常量是否同步（§20.7 那张表）、合订本是否重出。

5. **假设必须标注。**
   任何没有实验或数据支撑的结论，在文中要写成"假设"而不是"决定"。§19 的 34 个问题就是这条规则的产物。
