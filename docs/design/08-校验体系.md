只剩两组：**V 组看图，L 组看产物**。合并是任务，不是校验阶段。

## 9.1 V 组（图级，纯函数，不调模型）

| 码 | 检查 | 典型 hint |
| --- | --- | --- |
| `graph_schema_invalid` | 不符合 JSON Schema | 指出字段路径 |
| `node_id_dup` | 节点 id 重复 | 重命名 |
| `dep_missing` | 依赖指向不存在节点 | 列出合法 id |
| `dep_cycle` | 有环 | 返回环序列 |
| `write_overlap` | 两节点写同一路径 | 合并或加串行 |
| `write_outside_repo` | 绝对路径 / 越出仓库 | 用相对根路径 |
| `path_not_normalized` | `./`、`..`、`//` | 规范化后重提 |
| `acceptance_missing` | 缺验收 | 每节点必须有 |
| `acceptance_trivial` | `exit 0` / `true` / `--no-run` / 逻辑或恒真 | 空命令 |
| `required_not_in_writes` | 必填文件不在写集 | 补进 writes |
| `requirement_uncovered` | 需求条目无覆盖 | 列出未覆盖条目 |
| `covers_unknown_ref` | 引用不存在的条目 | 列出合法引用 |
| `too_many_files` / `node_too_big` / `too_many_nodes` | 粒度超限 | 再拆或两级拆解 |
| `base_commit_unknown` | 基线不存在 | 用当前 HEAD 重拆 |
| `writes_conflict_active` | 与在途任务写集相交 | 排后或改边界 |
| `interface_missing` | implement 祖先没有 interface | 补节点 |
| `interface_ambiguous` | 同模块多个 interface | 合并 |
| `interface_write` | 非 interface 节点写冻结接口 | 删掉这几行 |
| `test_missing` | implement 祖先没有 test | 补节点 |
| `test_write` | 非 test 节点写测试路径 | 删掉 |
| `consumes_unknown` | V7 符号未闭合 | 补 provides 或改签名 |
| `kind_topology` | 类型顺序错误 | 按 §7.8 重排 |
| `decision_tampered` | `decisions[]` 被改 | 恢复 |

## 9.2 L 组（产物级）

| 层 | 检查 | 谁跑 | 失败 |
| --- | --- | --- | --- |
| **L0 结构** | 路径 ⊆ `writes`；无 `..`/绝对路径/符号链接；单文件 ≤ 2MB；总计 ≤ 50MB | 平台 | `rejected` |
| **L1 完整** | 重算 sha256；`required_files` 齐全；冻结文件未被改动；编码统一 | 平台 | `rejected` |
| **L2 形状** | `schema_output` 过 JSON Schema；linter 零 error | 平台 | `rejected` |
| **L3 行为** | 按 `acceptance.kind` 执行 | 终端跑 + 平台按信任分复跑 | `rejected` → 重试 |

## 9.3 反作弊矩阵

| 作弊手法 | 防御 | 层级 |
| --- | --- | --- |
| 改软测试 | 测试独立任务 + 冻结 + 复跑覆盖 | L1 |
| 空命令 | 静态黑名单 + `strength` + 复跑看输出 | V3 / L3 |
| 空洞断言 | **红测试**：空洞断言在骨架上通过 → 拒 | L3 |
| 改接口蒙混 | 接口冻结 + 写集拒绝 | V2 / L0 |
| 越界提交 | 路径 ⊆ writes | L0 |
| 旧基线覆盖 | `base_commit` + `stale` + rebase | L1 / 集成 |
| 假日志 | 平台复跑（信任分）+ 日志结构校验 | L3 |
| 声称成功 | 只认退出码与测试结果 | L3 |

## 9.4 执行环境

| 场景 | 环境 | 网络 |
| --- | --- | --- |
| 终端本地跑 L3 | 终端自己的机器 | 终端负责 |
| 平台复跑 L3 | 容器，10 分钟上限 | 断网 + 包代理白名单 |
| 集成全量 | 容器，60 分钟上限 | 同上 |
