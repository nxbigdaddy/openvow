## 记录规则

1. 每跑完一个实验，追加一行：日期、编号、材料、产出的数字、结论、回写了哪一节。
2. 数字必须实测，不接受"大约""差不多"。
3. 结论只有三种：**成立 / 不成立 / 无效**。无效指样本坏了（材料不真实、切分者与验证者是同一人），要重跑。
4. 每条记录必须对应一次回写动作：改了哪个常量、加了哪条约束，或者明确写"不改，因为……"。
